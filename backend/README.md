# Експериментальний локальний API

Це однокроковий прототип: він не зберігає історію, не використовує гібридний
пошук чи порогову відмову та не перевіряє автоматично достовірність відповіді
моделі. Знайдені фрагменти можуть бути нерелевантними, а модель — помилятися.
API призначене лише для локальної розробки: автентифікації та контролю
доступу немає, тому не відкривайте його в мережу.

Потрібні Python 3.12, `uv`, запущений локально Ollama з `qwen3:8b` та
локальний корпус. За замовчуванням API використовує копію без помилково
атрибутованого запису ID 3984. Якщо копії ще немає, створіть її один раз із
вже зібраного корпусу:

```sh
cd ml
uv run python evaluation/audit_corpus.py \
  --report outputs/corpus-audit-v1.json \
  --filtered-output outputs/poems-uk-audited-v1.jsonl --quarantine-id 3984
cd ..
```

Файли не перезаписуються. Для іншої копії задайте `KOBZAR_CORPUS` шляхом до
JSONL перед запуском. Якщо корпус не існує або некоректний, запуск завершується
помилкою; немає автоматичного переходу на неперевірений корпус.

Запуск із кореня репозиторію:

```sh
uv sync --project backend
uv run --project backend uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

Для діагностики backend у VS Code виберіть `backend/.venv/bin/python` як
інтерпретатор: окреме середовище `ml/.venv` не містить залежностей API.

`POST /chat` приймає `question` і обов'язковий `mode`: `title` для
лексичного пошуку за назвою або `quote` для однієї цитати в лапках з
щонайменше чотирьох слів. Автоматичного вибору режиму немає.

```sh
curl -sS http://127.0.0.1:8000/chat \
  -H 'Content-Type: application/json' \
  -d '{"mode":"title","question":"Яку річку Україна називає братом у «Розритій могилі»?"}'
```

У відповіді є `experimental`, `status` (`generated` або `refused`),
`retrieval_status`, `answer`, `sources`, `model` і `corpus_sha256`. Джерела
містять ID, назву, URL, зміщення та текст фрагмента. `generated` означає
лише успішну генерацію, не те, що відповідь підтверджена: сама модель може
відмовити або помилитися. Якщо пошук не дав джерела, API повертає відмову
без виклику моделі. `not_found` не доводить, що твір або цитата не існують.

Помилка Ollama або неповна відповідь повертає HTTP 502, тайм-аут — 504,
помилка вводу — 422. Модель і адреса Ollama фіксовані; використання GPU не
перевіряється. Для оцінювання людиною див. [інструкцію](../ml/evaluation/HUMAN_REVIEW.md).
