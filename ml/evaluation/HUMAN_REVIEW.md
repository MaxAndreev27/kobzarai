# Незалежна перевірка людиною

Мета — окремо оцінити знайдені фрагменти та відповідь, не припускаючи, що
цитата автоматично підтверджує відповідь. Жодної оцінки людиною ще не
проведено; попередні development-набори й оцінки створені AI-асистентом.

1. Інша людина готує нові запитання та еталони з перевірених джерел, не
   переглядаючи нові результати моделі. Включіть запити за назвою та
   цитатою, неоднозначні запити і питання без підтвердженої відповіді.
   Для кожного зафіксуйте джерело, очікувану відповідь або причину відмови.
2. Збережіть еталони окремо від запитів до API; не надсилайте очікувані
   відповіді моделі. Зафіксуйте версію коду, `corpus_sha256`, digest моделі,
   параметри та набір запитань до запуску. Не використовуйте набір для
   налаштування системи, якщо він має залишатися holdout.
3. Надішліть кожне запитання окремо до API в явно вибраному режимі та
   збережіть повний результат або HTTP-помилку. Не припускайте, що
   `status=generated` означає правильну відповідь.
4. Експерт зіставляє результат з еталоном і джерелом. Для кожного випадку
   записуйте наведені нижче поля; залишайте `не оцінено`, коли підтвердження
   недостатньо. Джерелом мають бути фактичні тексти або надійні бібліографічні
   дані, а не відповідь моделі чи самі метадані корпусу.

| Поле | Варіанти |
|---|---|
| ID, запит, режим | Ідентифікатор, текст запиту, `title` / `quote` |
| Пошук | `правильний`, `неправильний`, `відмова доречна`, `відмова зайва`, `не оцінено` |
| Фрагмент | `підтверджує`, `не підтверджує`, `немає`, `не оцінено` |
| Відповідь | `правильна`, `часткова`, `неправильна`, `доречна відмова`, `зайва відмова`, `не оцінено` |
| Непідтверджені твердження | Так / ні / не оцінено; які саме |
| Джерело оцінки | Посилання, видання або опис і потрібний уривок |
| Коментар | Причина оцінки, неоднозначність, помилка корпусу чи HTTP-помилка |

5. Підрахуйте результати окремо для запитань із відповіддю та без неї:
   правильність пошуку, наявність підтвердження, якість відповіді, зайві
   відмови та вигадані твердження. Вказуйте кількість випадків у знаменнику,
   помилки запуску й випадки, які експерт не зміг оцінити.

Якщо результати використали для зміни пошуку, промпта, моделі чи порога,
цей набір більше не є незалежним holdout: для фінального порівняння потрібен
новий набір. Дані, що потребують приватності, не додавайте до Git.

## Початковий аркуш для людини

Ці запитання підготовлені AI-асистентом, який працював над системою, тому
**не є незалежним holdout**. Вони допоможуть провести першу людську перевірку
процесу. Людина має самостійно перевірити джерела та встановити очікувані
відповіді до запуску моделі. Частина запитань уже використовувалася у
попередніх development-прогонах; оцінки навмисно не заповнено.

| ID | Режим | Запитання | Джерело для ручної перевірки |
|---|---|---|---|
| human-01 | `title` | Що, за словами героя «Долі», зробила доля після настанови вчитися? | [«Доля»](https://www.ukrlib.com.ua/books/printit.php?tid=3992) |
| human-02 | `title` | Яким словом названо Богдана у «Розритій могилі»? | [«Розрита могила»](https://www.ukrlib.com.ua/books/printit.php?tid=23446) |
| human-03 | `title` | Як називається село, де народилася ворожка у «Причинній»? | [«Причинна»](https://www.ukrlib.com.ua/books/printit.php?tid=774) |
| human-04 | `title` | Порівняй «Тополя» та «Заповіт». | [«Тополя»](https://www.ukrlib.com.ua/books/printit.php?tid=784), [«Заповіт»](https://www.ukrlib.com.ua/books/printit.php?tid=729) |
| human-05 | `quote` | Звідки «Дніпро, брат мій, висихає, мене покидає»? | [«Розрита могила»](https://www.ukrlib.com.ua/books/printit.php?tid=23446) |
| human-06 | `quote` | Звідки «Дніпро брат мій за хмарами зникає»? | Перевірити самостійно; незнайдений у корпусі рядок не доводить його неіснування. |

У журнал оцінювання внесіть окремий рядок для кожного ID за полями вище.
Для незалежного фінального набору інша людина має підготувати нові запитання
та джерела, не використовуючи цей аркуш для налаштування.
