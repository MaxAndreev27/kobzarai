# KobzarAI frontend

Локальний Vue 3 / Vite інтерфейс до експериментального FastAPI. Це не
історична особа: модель може помилятися, а знайдені фрагменти — не містити
відповіді. Кожне запитання обробляється окремо, без історії діалогу.
Пошук автоматично шукає точну цитату або назву твору; знайдені фрагменти
показуються відкритими, але можуть не містити відповіді. За відсутності
однозначно знайденого джерела модель дає загальну відповідь, позначену як
не підтверджену корпусом. Пошук за змістом по всьому корпусу не виконується:
для пошуку вкажіть назву твору або одну цитату в лапках від чотирьох слів.
Явний запит знайти всі місця з одним словом — у лапках або без них після
слова «слово» — є винятком: backend
перевіряє всі тексти корпусу та показує кожен рядок зі збігом основи, зокрема
словоформи й похідні слова.

Потрібні Node.js 24, pnpm і запущений backend із локальним Ollama, моделями
`qwen3:8b` та `bge-m3:latest` і корпусом; див.
[інструкцію backend](../backend/README.md). Після запуску
backend на `127.0.0.1:8000`:

```sh
pnpm --dir frontend install --frozen-lockfile
pnpm --dir frontend dev
```

Відкрийте адресу, яку покаже Vite (зазвичай `http://127.0.0.1:5173`).
Vite проксує `/api/chat` на `http://127.0.0.1:8000/chat`. Для перевірки
збірки:

```sh
pnpm --dir frontend build
pnpm --dir frontend test
pnpm --dir frontend preview
```

І dev, і preview прив'язані до localhost та використовують однаковий
локальний proxy. `vite preview` не є production-сервером. При розгортанні
статичних файлів окремо необхідно налаштувати власний `/api` proxy; backend
не має автентифікації та не призначений для доступу з недовіреної мережі.
