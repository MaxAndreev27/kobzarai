# Security Policy

KobzarAI is an experimental project, not a production-ready service. The
current backend has no authentication and is intended for local use only.

Please do not disclose exploitable vulnerabilities or sensitive information in
public issues. Contact [@MaxAndreev27](https://github.com/MaxAndreev27)
through an available private channel. If none is available, open an issue
only to request a private reporting channel, without including vulnerability
details. Maintainers will assess reports on a best-effort basis.
